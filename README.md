# PulseNews AI

## Enterprise AI-Powered News Intelligence & Educational Knowledge Platform

PulseNews AI is an enterprise-grade platform that collects live news from trusted sources, detects breaking events, uses AI to summarize and organize information, and transforms it into exam-ready study material — MCQs, flashcards, revision notes, timelines, and a knowledge graph with a conversational AI tutor.

---

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Key Features

- **Short Video Feed** — TikTok-style vertical news reels with auto-play
- **Live Broadcast Hub** — Real-time live stream monitoring (NDTV, DW, NASA, Sky News)
- **AI Exam Digest** — Gemini-powered 3-bullet quick takes and MCQ generation
- **AI Tutor** — Multi-turn conversational chatbot for exam preparation
- **Knowledge Graph** — Interactive entity relationship explorer
- **Open News Studio** — RSS feed aggregator, article extractor, and batch summarizer
- **System Telemetry** — Real-time pipeline metrics and architecture monitoring
- **PDF Digest** — Downloadable daily current affairs compilation
- **Bookmarks & Quiz History** — Progress tracking with accuracy scoring
