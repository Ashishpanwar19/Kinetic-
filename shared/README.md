# shared/ — Shared Types and Utilities

This directory contains TypeScript types, interfaces, and utility functions shared across the frontend, backend, and AI services.

## Contents (to be populated in Volume 3+)

- `types.ts` — Shared domain types (KnowledgeObject, User, Article, MCQ, etc.)
- `constants.ts` — Shared constants (categories, exam types, source registry)
- `utils.ts` — Shared utility functions (date formatting, URL normalization, etc.)

## Usage

```typescript
import { KnowledgeObject, ExamCategory } from '../shared/types';
```
